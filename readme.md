# Step-by-Step Reinforcement Learning

Building reinforcement learning fundamentals from scratch, step by step.

## Steps

- **Step 1 (`step1`)**: Basic 2-armed bandit environment and random action sampling.
- **Step 2 (`step2.py`)**: Estimating action values using sample-average reward tracking.
- **Step 3 (`step3.py`)**: Implementing an $\epsilon$-greedy strategy to balance exploration and exploitation.
- **Step 4 (`step4.py`)**: Incremental value updates with learning rate ($\alpha$) and prediction error.

## How to Run

No external dependencies required (uses standard library `random`).

```bash
python3 step1
python3 step2.py
python3 step3.py
python3 step4.py
```
